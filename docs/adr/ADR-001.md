# ADR-001: WebXR Runtime and Scene Architecture on Immersive Web SDK (IWSDK)

- **Status:** Accepted
- **Date:** 2026-10-20

## Context

Talking Drum VR is a seated, hands-only WebXR game teaching Yoruba tonal patterns for the Meta VR Start Developer Competition 2026. It requires first-class Meta Quest Browser support, WebXR hand-tracking (`hand-tracking`), spatial UI (`@pmndrs/uikit-horizon`), and desktop testing via the Immersive Web Emulator (IWER).

## Decision

Build the application on **Immersive Web SDK (`@iwsdk/core` v1.0.1)** with **Three.js (`super-three@0.181.0`)**, **TypeScript (strict)**, and **Vite**. Configure `iwsdk.config.json` with `world.xr.mode = "vr"`, `world.xr.offer = "always"`, `world.xr.features.handTracking = true`, and locomotion/grabbing/physics disabled for M0.

## Consequences

- Declarative XR configuration and asset registration via `iwsdk.config.json`, `src/assets.ts`, and `public/scenes/main.iwsdk.scene.json`.
- Built-in IWER support (`metaQuest3` profile) for desktop verification without a physical headset.
- Zero controller-only code paths; seated hand-tracking is the primary interaction model.
