# ADR-005: Centralise All Spatial, Visual, and Gameplay Tunables in `src/app/config.ts`

- **Status:** Accepted
- **Date:** 2026-10-20

## Context

Spatial placement (e.g., talking drum distance ahead of the player and vertical offset below eye level), geometry dimensions, strike velocity thresholds, pitch-bend ranges, and diagnostic refresh rates require iterative tuning on Meta Quest hardware and in the Immersive Web Emulator.

## Decision

All tunable thresholds and constants must be defined in `src/app/config.ts` (`APP_CONFIG`) rather than scattered as magic numbers across ECS systems or asset modules. URL query flags (`?xrfps=1`, `?debug=1`) are parsed in `src/app/flags.ts`.

## Consequences

- Single source of truth for spatial ergonomics (`0.5 m` ahead, `0.35 m` below eye level) and future strike/audio parameters.
- Systems and procedural assets import typed values from `src/app/config.ts`.
