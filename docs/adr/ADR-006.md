# ADR-006: Trunk-Based Development and CI-Only GitHub Pages Deployments with Kill-Switch

- **Status:** Accepted
- **Date:** 2026-10-20

## Context

The Meta VR Start Developer Competition 2026 enforces a strict submission deadline (18 Nov 2026, 12:00 PT) after which the deployed build must remain frozen. Deploys must be reproducible, verifiable against sub-path 404 regressions, and immediately disable-able.

## Decision

1. Use short-lived feature branches (`feat/*`, `fix/*`, `chore/*`) merged into `main` via Pull Requests gated by the `ci` workflow.
2. Deploy to GitHub Pages exclusively via `.github/workflows/deploy.yml` on pushes to `main` and `v*` tags.
3. Gate both the `deploy` and `smoke` jobs on the repository variable `vars.DEPLOY_ENABLED == 'true'`, providing an instant kill-switch before the competition freeze deadline.
4. Configure Vite's `base` path from the single environment variable `BASE_PATH` (default `/talking-drum-vr/`).

## Consequences

- Setting `DEPLOY_ENABLED=false` in GitHub repository variables halts all Pages deployments without requiring a code commit.
- Post-deploy Playwright smoke tests verify zero console errors and zero 404s on the live URL.
